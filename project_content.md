# Knowledgegraph AI Platform - Project Documentation

## 1. Project Abstract
The **Knowledgegraph AI Platform** is a state-of-the-art system designed to transform unstructured information into interactive, visual knowledge graphs. By leveraging advanced Large Language Models (LLMs) such as Google's Gemini, the platform allows users to explore complex concepts, analyze technical documents, and understand programming logic through a dynamic, node-based visualization interface. The system aims to bridge the gap between static content and active learning by providing an immersive, context-aware exploration environment.

## 2. Project Objectives
- **Information Synthesis**: Automatically extract and structure key concepts from vast amounts of text and PDFs.
- **Visual Intelligence**: Provide a real-time, interactive graph interface for intuitive learning and relationship mapping.
- **Code Clarity**: Enable developers to visualize and navigate complex codebases through logic-flow diagrams.
- **Academic Support**: Assist researchers and students in understanding academic papers through AI-driven "deep dives" into specific modules.
- **Scalability**: Build a modular architecture capable of handling various input types (Query, Document, Code) with high performance.

## 3. Key Modules & Features
- **Query Mode**: Semantic search and graph generation for any topic.
- **PDF Mode**: Intelligent structure extraction and conversational AI analysis of research papers and books.
- **Programming Mode**: Logic-flow visualization and dependency mapping for multiple programming languages.
- **Interactive Workspace**: Force-directed graph layouts with node expansion and detailed "Deep Dive" capabilities.
- **AI Study Partner**: A context-aware chat assistant integrated directly into the exploration workspace.

## 4. Technology Stack
- **Frontend**: React.js, Framer Motion, Cytoscape.js, Radix UI.
- **Backend**: FastAPI (Python), Uvicorn.
- **Artificial Intelligence**: Google Gemini Pro/Flash (via Vertex AI/Generative AI API).
- **Database**: MongoDB (Session & History), Neo4j (Graph Storage), SQLite (Local Cache).
- **Visualization**: Cytoscape.js for high-performance graph rendering.

## 6. Future Scope
- **Real-time Collaboration**: Multi-user graph editing and sharing.
- **Cross-Document Analysis**: Linking concepts across multiple uploaded PDFs.
- **Custom Model Integration**: Support for local LLMs (Llama, Mistral) for privacy-focused environments.
- **Mobile Application**: Dedicated iOS/Android versions for on-the-go exploration.
- **Enterprise Integration**: API endpoints for third-party software integration.
